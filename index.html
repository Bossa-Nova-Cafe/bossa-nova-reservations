Marche à suivre — publier un événement
  1. Préparer l'image. Format 3:2 (800 × 532 px), en JPEG, sous 300 Ko. Nom du fichier sans accent ni espace : feijoada-octobre.jpg. Puis déposer l'image sur GitHub → Commit changes. Son adresse devient
  2. Créer l'événement dans le formulaire ci-dessous, en collant cette adresse dans le champ Image. Soignez la description : ses 300 premiers caractères servent d'aperçu sur les réseaux, prix compris.
  3. Générer la page de partage. Bouton Page réseaux sociaux sur l'événement, puis copier le contenu affiché.
  4. Créer le fichier : nouveau fichier sur GitHub, saisir le nom indiqué, coller, Commit changes.
  5. Partager l'adresse en .html après une minute — vérifier le site.

Deux boutons, deux usages : Lien à partager donne l'adresse technique, pratique en interne ; Page réseaux sociaux prépare la page avec photo et description, pour Facebook et WhatsApp. Instagram n'affiche jamais d'aperçu de lien : l'adresse va en bio ou en story.

Si vous modifiez l'image ou la description d'un événement déjà diffusé, régénérez la page, remplacez le fichier, puis ajoutez ?v=2 au lien pour forcer WhatsApp à oublier son cache. Pour Facebook, passer par son outil de débogage.
